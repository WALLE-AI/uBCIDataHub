# 门户交互原型验收记录

日期：2026-11-16

## 交付范围

- 四个可通过本地 HTTP 服务访问的页面：首页、资源目录、资源详情、使用指南。
- 六个明确标识的演示数据集及对应结构、质量、版本和访问说明。
- 可按关键词、病种、模态、任务、访问方式、多中心、随访、受试者规模和采样率筛选。
- 可通过 URL 恢复条件，支持排序、分页与详情返回。
- 机构、数据、计算和需求登记的申请演示；含校验、核对、失败重试及完成反馈。
- 可展开的六步治理流程。
- 五层技术架构图：独立 SVG、1680 × 1420 PNG、网页展示与下载入口。

## 内容及边界确认

- 资源、人数、时长、质量指标及报告明确标为示例；不代表平台实际运营规模。
- 开放资源没有真实信号文件，下载按钮引导至使用说明。
- 申请不发送请求、不生成真实受理单，不持久化联系方式。
- 架构图表达目标能力与建议接口，不表示模型服务或标准认证已完成。
- 原始研究文件未改动，原门户保留为参考。
- 真实目录、身份认证、授权、审批、数据交付和模型计算需后续接口接入。

当前验证覆盖交互原型，不包含真实后端集成、实际临床数据质量、屏幕阅读器人工测试或多浏览器兼容认证。
